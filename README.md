ilia-info 🐧

A simple Linux system information tool written in Python.

Features

- Operating system
- Kernel version
- CPU information
- Hostname
- Disk information

Installation

Build the Debian package:

dpkg-deb --build ilia-info-deb

Install it:

sudo apt install ./ilia-info-deb.deb

Then run:

ilia-info
